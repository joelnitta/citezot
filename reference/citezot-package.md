# citezot: Pull Cited References from Zotero into Quarto Bibliographies

Scans Quarto and R Markdown documents for citation keys, pulls the
matching items from the Zotero web API, and writes a bibliography file.
Also provides dry-run-by-default helpers to find, add, and update Zotero
items.
